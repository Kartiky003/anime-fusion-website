# 🎌 Anime-fusion-Website

A responsive Anime Website built using **HTML** and **CSS**. This project showcases a modern anime-themed user interface with a clean layout and responsive design.

## 🚀 Features

- Responsive Design
- Modern UI
- Hero Banner
- Anime Cards
- Navigation Bar
- Footer
- Clean Layout
